# Thesis Proposal: StyleSync

## Робоча назва проєкту

**UA:** Розробка вебсистеми персоналізованого підбору та управління гардеробом
**EN:** Development of a Web System for Personalized Wardrobe Management and Outfit Recommendation

## Актуальність та проблематика

Управління особистим гардеробом ускладнюється зростанням обсягу речей, відсутністю систематизації та браком інструментів для об'єктивного підбору комбінацій одягу. Існуючі рішення не забезпечують автоматизованого аналізу характеристик речей і не враховують контекстні фактори — сезон та історію вподобань користувача. Задача полягає у створенні системи, що поєднує комп'ютерний зір для автоматичної класифікації одягу за фотографією з рекомендаційним алгоритмом, здатним формувати релевантні комбінації речей при масштабованому навантаженні на етапі обробки зображень.

## Сформована ідея продукту

Подієво-керована мікросервісна платформа, що складається з основного backend-сервісу (бізнес-логіка, користувачі, гардероб) та виділеного ML-інференс-сервісу для аналізу зображень, які взаємодіють асинхронно через брокер повідомлень. Дані про речі та embeddings для рекомендацій зберігаються у реляційній базі, а пошук схожих речей для рекомендацій реалізовано на рівні прикладного коду (обчислення косинусної схожості embeddings).

## Core Features

1. Реєстрація та автентифікація користувачів (JWT, OAuth2/OIDC).
2. Асинхронний CV-аналіз фото речей (тип, колір) через окремий ML-мікросервіс із чергою повідомлень і статусом обробки.
3. Автоматична категоризація та тегування речей на основі виходу ML-моделі.
4. Рекомендаційний рушій формування образів (content-based filtering на embeddings) за стилем і сезоном.
5. Врахування фідбеку користувача (лайк/дизлайк) через перерахунок вектора вподобань.
6. Аналітика гардеробу: статистика використання речей, капсульний гардероб.
7. Кешування рекомендацій для зниження латентності.
