# ВСТУП

## Актуальність теми

Актуальність теми зумовлена необхідністю розв'язання інженерної задачі обробки зображень у реальному часі в умовах обмежених обчислювальних ресурсів клієнтських пристроїв. Традиційні системи каталогізації одягу не забезпечують масштабованої обробки зображень при одночасному зверненні множини користувачів, що призводить до зростання затримок (latency) синхронного аналізу та зниження відмовостійкості (fault tolerance) системи при пікових навантаженнях. Додатковим викликом є забезпечення безпеки передачі персональних даних між компонентами розподіленої системи. Розв'язання зазначених проблем вимагає застосування асинхронної, подієво-керованої архітектури з чіткою ізоляцією ресурсомістких обчислювальних процесів від основного потоку обробки запитів користувача.

## Об'єкт дослідження

Процес персоналізованого підбору та управління цифровим гардеробом користувача на основі автоматизованого аналізу зображень одягу та рекомендаційних алгоритмів.

## Предмет дослідження

Методи й моделі комп'ютерного зору для класифікації характеристик одягу за зображенням, алгоритми рекомендаційних систем на основі векторних представлень (embeddings), а також архітектурні патерни асинхронної взаємодії компонентів розподіленої програмної системи.

## Мета роботи

Проєктування та розробка розподіленої програмної системи персоналізованого підбору гардеробу, що забезпечує якісне підвищення швидкодії та масштабованості обробки зображень одягу за рахунок асинхронної мікросервісної архітектури.

## Завдання проєкту

1. Проаналізувати існуючі аналоги систем управління гардеробом та рекомендаційних сервісів одягу.
2. Обґрунтувати вибір технологічного стеку для реалізації розподіленої архітектури системи.
3. Спроєктувати архітектуру програмного забезпечення з використанням нотації UML/C4 Model.
4. Розробити алгоритм рекомендаційного рушія на основі векторних представлень (embeddings) зображень одягу.
5. Спроєктувати інтерфейс користувача та схему розгортання програмного комплексу.
6. Провести інструментальний аудит якості коду засобами автоматизованого тестування.
7. Підготувати науково-практичну апробацію результатів дослідження (публікація тез/статті).
